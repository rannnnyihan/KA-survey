# HTML 交付物格式规格（固定 · 勿随地区/时间改动）

> 本规格是 HTML 交付物的**唯一格式标准**。换地区、换时间只允许改「地区名、简称、日期、数据内容」，其余（指标、维度、权重、评分、排名规则、页面结构、颜色）一律与首发上海版**完全一致**。改版前先读本规格，改完必须同步更新本文件与 `scripts/gen_evidence_html.py`。

## 零、核心原则（硬约束）

| 项目 | 是否可变 |
|---|---|
| 地区名 / 简称 / 日期 / 证据内容 | ✅ 随用户输入变 |
| 21 项指标 | ❌ 固定 |
| 六大类维度（需求/资本/供给/技术/盈利/政策） | ❌ 固定 |
| 权重（20/10/20/20/20/10） | ❌ 固定 |
| 评分分档表（scoring-standard-industry.md） | ❌ 固定 |
| 排名规则（唯一行业全榜、同分按代码） | ❌ 固定 |
| NS 行业映射（37 组） | ❌ 固定 |
| 页面结构 / 列 / 抽屉 / 颜色 | ❌ 固定 |

## 一、页面整体

1. **单文件 HTML**，无外部依赖（不引 CDN、不引外部字体/JS），浏览器直接打开即用。
2. 标题 `<h1>`：`{地区} 70 细分行业 · 综合评分与证据库`，右上角小字显示日期 `YYYY-MM-DD`。
3. 副标题 `<p class="sub">`：一句话说明「覆盖 70 个细分行业、每格证据=数字+年份+来源层级+可点击出处、缺格标「缺{简称}数据」、评分按 21 指标六大类 100 分制」。
4. meta-card 元信息条（4 个徽章）：覆盖行业数 / 评分指标「21 项·六大类」/ 有证据指标（X/Y，百分比）/ 口径「仅{地区}」/ 优先级「S1 {地区}官方 ＞ S2 在{简称}行业一手 ＞ S3 权威第三方{简称}口径 ＞ S4 转载」。

## 二、主表（施耐德 NS 行业 × 国标行业综合排名）

- 表标题：`施耐德 NS 行业 × 国标行业综合排名`。
- 工具栏（标题下第一行）：搜索框 + 分数筛选下拉 + 命中计数。
  - 搜索：按行业名/代码/证据文本模糊匹配。
  - 分数筛选：全部 / 总分≥70 / 60–70 / <60。
- 权重滑杆区（工具栏下）：六大类滑杆（需求/资本/供给/技术/盈利/政策），默认值 **20/10/20/20/20/10**；合计恒为 100，拖动任一滑杆其余按比例分配；「恢复默认」按钮一键复位。**只调大类滑杆，不做类内细分滑杆。**
- 表格 **12 列**，从左到右固定：

| # | 列名 | 内容 |
|---|---|---|
| 1 | 排名 | 全榜排名（NS 行=组排名，国标行=全榜 #1–#70） |
| 2 | 行业 | 行业名（NS 行带 tag 徽章，国标行缩进+└） |
| 3–8 | 需求/资本/供给/技术/盈利/政策 | 六大类得分 |
| 9 | 总分/100 | 综合分（绿色徽章） |
| 10 | AI 摘要 | 一句话上海口径证据摘要 |
| 11 | 证据 | X/21（21 项中有证据支撑的项数） |
| 12 | 置信度 | 高/中高/中/低 彩色徽章 |

## 三、NS 一级行

- 显示：NS 行业名（加粗）+ **tag 徽章**（保/增/拓/其它，配色见第八节）+ 「N 个行业」计数 + 展开箭头 ▸/▾。
- 排名列：NS 组排名（按 NS 均分，组间排序）。
- 六大类得分：该 NS 组下成员国标行业**各类分的均值**。
- 总分：NS 行业分 = 成员国标行业总分**均值**。
- 行为：点击整行展开/折叠二级国标行业行。
- **tag 仅作标注，不参与排名**。

## 四、国标二级行

- 缩进显示，行业名前加 `└` 层级标记。
- 排名列：**全榜真实排名**（#1–#70，按唯一国标行业代码去重排序，同一行业归入多个 NS 组时共享同一名次）。
- 六大类得分 + 总分（绿色徽章）+ AI 摘要 + 证据数/21 + 置信度徽章。
- 行为：点击行 → 打开右侧抽屉。

## 五、右侧抽屉（点国标行业行打开）

依次包含（顺序固定）：

1. **头部**：行业名 + 全榜排名徽章（「全榜第 N 名」）+ 综合得分 X/100 + 证据数 X/21（含进度条）+ 关闭按钮 ✕。
2. **{地区}产业形态与背景**面板（默认展开）：客观事实描述（本地形态/载体企业/全国口径背景）+ 证据可信度标签。
3. **六大类得分**条：需求/资本/供给/技术/盈利/政策，每类一条得分条 + 数值（满分=类权重）。
4. **21 指标明细**（按六大类分组折叠面板）：每个指标一行 = 得分条 + `得分/满分` + 评分理由 note + 该指标的支撑证据格（含来源层级标签、年份、可点击链接）。
5. **官方与宏观指数基准**面板（若有）：标注「对照 · 不参与评分」。

## 六、底部方法口径（foot）

固定四段：① 采证口径与来源层级（S1–S4 定义）；② 缺格标注说明；③ 评分标准（21 指标/六大类/100 分制 + 滑杆说明）；④ 排名决胜规则（唯一行业 1–N 不并列、同分按行业代码）+ 采证时间 + 免责声明。

## 七、交互行为

- **搜索**：过滤主表行（NS 行 + 国标行同步）。
- **分数筛选**：按总分区间过滤。
- **权重滑杆**：实时重算六大类加权分与总分，并重排；合计锁 100。
- **NS 展开/折叠**：点击 NS 行切换其下国标行的显示。
- **抽屉**：从底部隐藏的 `#list` 卡片区克隆内容（`#list` 必须保留 `display:none`，删 DOM 会坏抽屉）。
- **排名**：前端 `recalc()` 必须按 `data-code` 去重排序（rankOf），避免同一行业多组映射重复占位挤乱名次。

## 八、颜色/样式规范（浅色主题）

- 主题：浅色背景 `#f7f8fa`，卡片白底，正文深色 `#1c2733`，主色蓝 `#0f62fe`。
- **总分徽章**：绿底绿字（`#e7f6ee`/`#0f8a4d`）。
- **置信度徽章**：高=绿、中高=黄、中=橙、低=灰。
- **NS tag 徽章**：保=蓝、增=绿、拓=黄、其它=灰（徽章底色同系浅色）。
- **NS 左侧竖条**：保=蓝 `#3b82f6`、增=绿 `#10b981`、拓=黄 `#f59e0b`、其它=灰 `#9ca3af`。
- **来源层级标签（S1–S4）**：S1=绿、S2=蓝、S3=橙、S4=灰。

## 九、固定不变清单（每次生成前自查）

1. 指标 = 21 项、维度 = 六大类、权重 = 20/10/20/20/20/10 —— 三者与上海版一致。
2. 评分分档表 = scoring-standard-industry.md —— 不因地区改动。
3. 排名 = 唯一国标行业全榜，同分按行业代码 —— 不并列。
4. NS 映射 = 37 组（ns-industry-mapping.md）—— 不因地区改动。
5. 页面结构/列/抽屉/颜色 = 本规格 —— 不因地区改动。
6. 唯一可变量：地区名、简称、日期、数据内容（证据文本/年份/链接）。
