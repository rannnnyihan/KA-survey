# MCP 连接器使用指南（含未连接时的用户引导流程）

本 skill 主力工具是 **WebSearch / WebFetch**（公开采证），MCP 连接器用于**企业级与金融数据补充**。用到未连接的 MCP 时，必须先弹卡片引导用户配置，不得静默跳过或编造数据。

## 相关 MCP 一览

| Connector | 提供能力 | 典型用途 | 优先级 |
|---|---|---|---|
| `kuaicha-search` 同花顺快查 | 企业排名、工商信息、行业筛选 | 行业龙头锚定、TopN 企业证据（配合 industry-region-top50-evidence skill） | 高（已验证） |
| `qcc-company` 企查查 | 工商注册、股东、对外投资、上市信息 | 载体企业核验、资本进入维（对外投资/增资） | 高 |
| `tyc-mcp` 天眼查 | 企业画像、按行业/地区/排名搜企业、招投标、专利 | 龙头企业筛选、专利（技术维辅助） | 中 |
| `sq-company-dynamic` 上奇产业通 | 企业全生命周期动态（认证/投资/用地/招聘/标准） | 供给维补充（招聘扩张=产能信号）、政策事件 | 中 |
| `qixinhuiyan-mcp` 启信慧眼 | 企业洞察 API（筛选/解析/检索） | 企业批量筛选 | 备选 |
| `wind-finance` Wind | 宏观 EDB、行业财务、指数、公告 | 盈利/资本维上市公司口径数据 | 高（金融口径） |

## 使用前检查流程

1. **查可用性**：用 ToolSearch 按工具名查（如 `tool_names: ["mcp__kuaicha-search__discover"]`），或在会话 connector-status 中确认状态。
2. **已连接** → 直接调用，证据照常写入 cell（tier 按来源定级）。
3. **未连接** → 走弹窗引导（见下），**不得**在未连接时假装调用或用编造数据顶替。

## 未连接时的弹窗引导（必须遵守）

读取 `recommend-connectors` skill 并调用 `suggest_plugin_install`，以卡片形式向用户推荐当前任务**直接需要**的 Connector（一次最多 3 个，只推荐未连接的）。同时给出简短配置指引文案：

> 该步骤需要 {Connector 名} 提供的 {能力}。请在弹出的卡片中点击连接并按提示完成授权；连接后告诉我"已连接"，我会继续采集 {行业/维度} 证据。若暂不连接，我将改用公开检索（覆盖度可能降低）。

要点：
- 弹卡片（suggest_plugin_install）而不是文字列表；
- 一次调用只提交一种分组（connector），最多 3 个候选；
- 用户跳过/取消后，同一轮**不得重复推荐**相同候选，改用 WebSearch 降级方案并说明覆盖差异；
- 推荐时机：进入采证前统一检查一次，避免流程中途反复打断。

## 与本 skill 数据流的衔接

- MCP 取得的企业/财务数据 → 转成标准 cell（`{dim, ind, ev, year, tier, urls}`）→ 走同一套四规则合并与评分，不另设口径。
- MCP 来源的 tier 判定：官方接口直出=S1/S2；平台聚合页=S3。
- 涉及企业排名类需求（TopN 企业证据表）时，联动 `industry-region-top50-evidence` skill 处理，本 skill 专注行业级六维证据库。
