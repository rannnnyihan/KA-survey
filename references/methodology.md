## 采证口径

1. **只收目标地区口径**。全国数据可作背景，但 ev 文本必须追加"（全国口径/代理数据，不计入沪上评分）"标记 + `national: true`，评分时按中性处理。
2. **来源层级**：S1 地区官方（统计局公报年鉴、经信/发改、行业主管委办、海关分关、监管在地单位）→ S2 在地一手（在地上市公司公告、央企国企官网、行业协会、主流媒体）→ S3 权威第三方但本地口径（券商研报本地章节、招聘/创投平台本地数据）→ S4 一般转载（极少采用）。
3. **诚实缺格**：检索不到就标 `miss: true`、ev 写"缺沪数据（原因）"，宁缺勿假，不拿全国口径顶替。
4. **时效优先**：优先最近季度（上半年/二季度/1-N月）；被替换旧证据入 `hist` 留档，不删除。
5. **链接必须是具体来源页**，不是官网首页（详见 evidence-sources.md 的链接卫生规则）。

## 打分算法（证据驱动，非主观评级）

### 第 1 层：单条证据方向与票数（cell_sign_w）

- 方向投票：正向/负向**百分比数字**各记 2 票（数字比词可靠），方向词（POS_WORDS/NEG_WORDS 词表见脚本）各记 1 票，多者定方向。
- **强信号加权**：该条证据中出现的最大百分比幅度 ≥20% → 整条记 2 票；≥50% → 记 3 票（默认 1 票）。这样"净利+163.51%"与"微增+2.4%"不再等权。

### 第 2 层：维度原始分（dim_score，1–5 连续值）

```
base = 1 + 4 × 正票 / (正票 + 负票)
收缩：shrunk = (base × n + 3.0 × pseudo) / (n + pseudo)   # 向中性3收缩
```

- 信号数 n = 正票 + 负票（`全国口径` 与 miss 格不计）。
- **单向信号权衡**（防负向偏坡 / 防证据稀疏虚高）：
  - 单向且票数 ≥3 → 真实方向，pseudo=2，标"全正/全负信号"
  - 单向且票数 ≤2 → 可能缺反向信息，pseudo=3（更强收缩），标"⚠ 单向弱正/弱负"
  - 双向 → pseudo=2
- 有证据但无方向词 → 3.0 中性。

### 第 3 层：汇总（100 分制）

```
维度加权贡献分 = 原始分 ÷ 5 × 该维权重
综合信号分 score100 = Σ 六维加权贡献分
```

- **无证据维度按中性 3 分计入**（防止证据少的行业因选择性取证虚高）；六维全无证据不评级。
- 页面各处展示的维度分均为**加权贡献分**（满分=该维权重）；5 分制原始分只是中间量，不展示。

### 排名与分级

- 分级：≥80 信号强 / ≥65 中强 / ≥50 中 / ≥35 中弱 / <35 弱 / 无数据 证据不足。
- 平级决胜：综合分(0.01精度) → core_filled → 正向信号总票数 → 行业代码，严格 1–N 不并列。

## 排名偏差诊断手册（重要经验）

当用户指出"某行业理论上应排很高但排名低"时，按此排查（2026-09-02 上海案例：医药#13、铁路船舶航天#9，实际无一条负向证据）：

1. **先复现判定**：`from rescore_evidence import cell_sign_w` 逐格跑，确认是否有负向证据触发词误伤。
2. **看每维有效证据票数**：若某维只有 1–2 条正向证据 → 触发"单向弱正"强收缩（pseudo=3），超强证据（+163%）也只值 2–3 票。这是结构性低分，不是行业差。
3. **修复优先级**：
   - **首选补证据**：为稀疏维度检索目标地区最新强证据，按 R1/R3 规则合入（最诚实，不改方法论）；
   - 算法层已含强信号加权（≥20%→2票、≥50%→3票）与单向弱正 pseudo 4→3 两次修正，勿再轻易改动；
4. **全量重算后必须做前后对照**：快照旧排名（备份 `rank_before.json`），检查无行业分数变动超 ±10、异常升降要能解释。
5. 集团口径公司（如"上海医药集团"营收）不算本地行业证据，须用在地产业口径（统计局行业产值、在地上市公司）。

## 迭代操作：合并新证据 CSV（四规则）

外部（如 Codex 子代理产出的逐项支持链接 CSV）合入主库：

- **R1 缺格创建**：主库无该 (code,dim,ind) 格且 CSV 有带链接证据 → 新建。
- **R2 miss 转正**：主库格 miss=true 但 CSV 有带链接证据 → 填充转正，旧文本入 hist。
- **R3 择新替换**：CSV 年份严格更新且为本地口径（或旧证据本就是代理口径）→ 替换，旧证据入 hist。
- **R4 hist 补充**：其余未重复文本 → 追加 hist 留档（按 ev 前 40 字去重）。

合并细节：ALIAS 指标别名映射、TO_SUPP 强制归入"补充"维、T1→S1 层级转换、无链接行直接跳过。合并前**必须备份主库**，合并后重算 filled/missing/core_filled 并跑 rescore。

## 链接卫生规则

- 每条证据的 urls 必须指向**具体文章/公报/公告页**；禁止放 `tjj.sh.gov.cn` 这类站点首页占位。
- 已存量首页链接的清洗：取 ev 中关键数字/标题做 WebSearch（`site:` 限定同域名），找到具体页后只替换 URL、不改 ev 文本；找不到则保留首页链接并在 HTML 中自动标"栏目首页"。
- `host_path_bare()`（gen 脚本内）判定首页型 URL，页面自动降级标注"栏目首页"提示复核。
