# 采证操作手册：平台、检索方式与逐格策略

## 采证总流程（70 行业 × 19 核心指标）

每个行业一条 record，每格证据 = `数字/事实 + 年份 + tier + 具体来源URL`。建议并行派发多个采证子代理（Agent 工具，general-purpose，run_in_background），每个子代理负责 10–15 个行业，产出统一 CSV（格式见 data-schema.md）后走 merge_evidence_csv.py 四规则合并——比直接写 JSON 更稳。

**子代理 prompt 模板要点**（可直接改地区词复用）：

> 你是行业采证代理。对以下行业（GB/T 4754 代码+名称）：{列表}，逐个采集六维证据（需求/供给/盈利/资本/技术/政策，19个核心指标见附表）。
> 口径：只收{地区}本地数据；全国数据仅在 ev 末尾标注"（全国口径/代理数据，不计入沪上评分）"。检索不到写"缺{地区简称}数据（原因）"。
> 优先级：S1 {地区}官方（统计局/经信委/发改委/主管委办/海关）> S2 在地一手（上市公司公告/央企国企官网/行业协会/主流媒体）> S3 权威第三方本地口径 > S4 转载。
> 每条证据必须给具体来源页 URL（禁止官网首页），用 WebSearch 检索，site: 限定优先。
> 输出 CSV 12 列：排名,代码,行业名称,分数,维度,指标,状态,年份,层级,证据,链接数,链接(；分隔)。

## 检索配方（按维度）

| 维度 | 高产检索词模式（{R}=地区名） |
|---|---|
| 需求 | `{R} {行业} 2026 产值 增长` / `{行业} 出口 {R}海关 2026 上半年` / `{R} {行业} 市场规模` |
| 供给 | `{R} 规上工业 {行业} 增加值 2026` / `{R} {行业} 产能利用率` / `{行业} 供给瓶颈 2026` |
| 盈利 | `{R} {行业} 龙头 2026 半年报 净利` / `{行业} 利润率 2026 {R}` |
| 资本 | `{R} {行业} 固定资产投资 2026` / `{R} {行业} 融资 2026 上半年 金额` |
| 技术 | `{R} {行业} 技术突破 2026` / `{行业} 量产 商业化 {R} 2026` |
| 政策 | `{R} {行业} 行动方案 2026 site:gov.cn` / `{R} 十五五 {行业}` / `{R} {行业} 补贴 支持` |

- 数字是硬通货：产值/增速/金额/订单额/获批数，比定性描述票数高（百分比 ≥20% 记 2 票、≥50% 记 3 票）。
- 用 ev 中的**关键数字+关键词**做 WebSearch（避免整句复制无结果）；`site:shanghai.gov.cn`、`site:tjj.sh.gov.cn` 等限定同域。
- 新地区对应替换官方域名（如北京 `tjj.beijing.gov.cn`、深圳 `sz.gov.cn` 下属部门）。

## 高价值来源类型（上海版实测）

1. **市/区统计局**：规上工业分行业产值/增加值、半年报快讯（分区口径常比市级更细）。
2. **经信委/发改委**：产业行动方案、专项资金、先导产业母基金、"十五五"规划。
3. **在地上市公司**：半年报/业绩预告（营收、净利、毛利率——盈利维最强证据）。
4. **海关分关**：出口数据（需求维出口增长格）。
5. **央企国企官网+主流媒体**：订单、投产、里程碑（交付/首飞/中标类正向词）。
6. **行业协会/创投平台**：融资额、企业数（资本维）。
7. **宏观指数**（另行存 macro_indices.json，对照不评分）：制造业 PMI、非制造业商务活动指数、EPMI、PPI、产能利用率、FAI 分行业增速。

## 缺格与去重

- 缺格 ev 规范：`缺{简称}数据（{原因}）`，如"缺沪数据（无本市口径统计，仅全国数据）"。
- 全国口径背景也可放 miss 格的说明里（34 个 miss 格携带全国背景是正常状态，非缺陷）。
- 文本去重以 ev 前 40 字为键（merge 脚本 hist_add 同款逻辑）。

## 补证专项数据源（实测高效）

- **企业注册热度 / 企业法人单位数**：用统计局《统计年鉴》的「按行业(大类)、登记注册统计类别分组的企业法人单位数」表，一次覆盖全部行业大类，S1 官方一手，且与全国经济普查公报口径可交叉验证（上海实测：年鉴 737,641 家 ≈ 五经普 73.8 万）。上海 URL：`tjj.sh.gov.cn/tjnj/.../A2-09.xls`。采矿业大类（06-12）在该表通常为空 → 如实标「{地区}无本地采矿业，企业法人单位数无公开口径」。注意该数据为**滞后一年**口径（2026 年查到的多为 2023 年末），如实标年份即可。
- **龙头企业收入增长**：在地上市公司年报营收增速即可（医药→上海医药/复星/君实，汽车→上汽，专用设备→中微/上海电气）。集团口径须在 ev 里标注"非本地分部单列"。
- **融资活动增长**：搜「{地区} {行业} IPO/并购/融资 2025」找具体事件+金额（如"友升股份拟募资24.71亿过会"）。

## 质量红线

- ❌ 拿全国数据顶替本地口径且不标"全国口径"
- ❌ 官网首页 URL 占位（必须具体文章页）
- ❌ 集团口径冒充本地行业口径
- ❌ 自造"行业景气指数"——全国并无覆盖 70 细分行业统一口径的官方景气指数；排名只能用自建证据信号分并在页面声明口径
- ❌ **估计值 / 无来源数字**——采证阶段若写入"约+3.5%"这类无法溯源的估计数字，后期 URL 无法替换为具体页（实测 74 个首页链接中 47 个是估计值无法溯源）。采证 prompt 必须明令：每条证据数字都必须来自可溯源的具体文章页，查不到就如实标"缺数据"，禁止估计。
