# 上海 70 行业多维指标证据库

上海 70 个国民经济细分行业（GB/T 4754 大类）的多维指标证据库，按「施耐德 NS 行业 × 国标行业」两级结构组织，含权重滑杆实时重算、右侧抽屉下钻、可折叠维度面板的单文件交互 HTML。

> 面向业务（非技术）同事的功能说明，请见 **[功能说明.md](功能说明.md)**。

## 内容

- **`上海70行业多维指标证据库_2026-09-02.html`** — 交付物（单文件，无外部依赖，浏览器直接打开）
- **`scripts/`** — 生成脚本套件
  - `rescore_ind21.py` — 行业评分引擎（21 指标 · 六大类 · 100 分制，分档评分）
  - `gen_evidence_html.py` — 交互 HTML 生成器（NS/国标两级表、抽屉、权重滑杆）
  - `rescore_evidence.py` — 早期信号法评分引擎（已弃用，保留备查）
  - `merge_evidence_csv.py` — 证据 CSV 四规则合并
  - `adapt_region.sh` — 跨地区适配（sed 替换地区词与路径）
- **`references/`** — 方法论与口径文档
  - `scoring-standard-industry.md` — 行业 21 指标分档评分标准（现行）
  - `methodology.md` — 评分算法与排名诊断手册
  - `data-schema.md` — 主库 JSON / CSV 结构
  - `evidence-sources.md` — 采证检索配方与质量红线
  - `ns-industry-mapping.md` — 施耐德 NS 行业 ↔ 国标行业映射
  - `mcp-connectors.md` — MCP 数据源清单与连接检查
- **`SKILL.md`** — 可跨地区复用的工作流说明

## 口径

- 证据口径：仅上海本地数据；全国口径标「全国口径」不计分；检索不到如实标「缺沪数据」。
- 评分：六大类 需求20 / 资本10 / 供给20 / 技术20 / 盈利20 / 政策10，21 项指标分档制。
- 数据时点：以 2026 年最新季度为主（部分为统计年鉴滞后口径，已如实标注年份）。
